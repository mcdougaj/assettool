Instructions

  1. Load an Excel (.xlsx) file using the button below
  2. Drag columns from "Available Columns" to set up your hierarchy:
    • Parent Column: Top level of hierarchy
    • Child Column: Second level items
    • Description: Optional details for each item
  3. The treeview will update automatically as you map columns
  4. Use "Show Orphan Records" to view items without parents
  5. Click "Save Changes" to export your modified hierarchy
